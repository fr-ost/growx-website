# Directory copy

Copy blocks sized for typical directory and launch-site forms (Product Hunt, AlternativeTo, SaaSHub, BetaList, Uneed, AI tool
directories and similar). Every count below was measured with a script and includes spaces and punctuation; in multi-line blocks each
line break counts as one character. All text is plain ASCII, so the counts match what forms see.

**Rules for using it**

- Use the **same name and primary short description everywhere**. Consistent details help search engines connect the listings.
- Check prices on https://www.growxapp.org/pricing before you submit; the website is the source of truth.
- Facts match extension v2.4.4 (`docs/PRODUCT_FACTS.md`). If the extension changes, update that file first, then this one.
- No ratings, user counts, testimonials or promised results in any field, even when a form asks for "traction".
- Logos, screenshots and a badge are on https://www.growxapp.org/press.

## Long description

**Long description** (990 characters; limit 1000)

```text
GrowX is an all-in-one Chrome extension for growing on X (Twitter). It works inside your own signed-in x.com session, never asks for your X password and keeps your data in your browser.

- Grow: smart auto follow finds the newest followers of accounts in your niche, scores them for follow-back and follows at a human pace with breaks and caps, slowing down or stopping when X warns.
- Create: posts and threads, post now, schedule or add to queue slots, and your best time to post from your own data.
- GrowX AI (Premium): write, improve and find hooks with the AI built into Chrome. It runs on your computer; no API key.
- Insights: views, engagement rate, what topics and formats work, and who followed or unfollowed you.
- Engage and Cleanup: reply targets for fresh posts, and a safe-paced cleanup of accounts that don't follow back.

Free forever, with a 30-day Premium trial and no card needed. No tool can promise zero risk on X. GrowX is independent and not affiliated with X Corp.
```

**Q: Is auto follow safe for my X account?** (37 characters)


**Q: Where is my data stored?** (24 characters)

```text
In your browser. Settings, queue, history, posts and analytics stay in Chrome's storage, and no GrowX server holds your X data. Optional sync uses Chrome's own sync, and anonymous usage counts can be switched off.
```
